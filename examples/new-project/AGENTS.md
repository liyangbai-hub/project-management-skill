# 项目工作协议

本示例用于演示模式一创建受管项目后的最小接力入口。

## 开工顺序

1. 阅读本文件。
2. 阅读 `README.md`。
3. 阅读 `DEVLOG.md` 的“当前状态”和末尾相关工作单元。
4. 阅读 `requirements/INDEX.md`，确认是否有待评估材料。
5. 查看 `src/main.txt`，核验 README 对当前源码入口的描述。

## 改动与验证

- 实质改动前在 `DEVLOG.md` 追加计划。
- 完成后追加结果、变更文件、验证状态和遗留项。
- 保留 `src/` 原生源码布局，不创建强制的 `技术/` 目录。
- 本示例没有外部依赖；不要凭文档声称存在未执行的运行测试。

## 安全与授权

- 不写入真实凭据、私钥或个人数据。
- 不删除、覆盖或移动文件，除非用户明确授权具体范围。
- 不执行远程 GitHub 操作。
