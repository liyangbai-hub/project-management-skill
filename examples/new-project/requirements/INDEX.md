# 输入材料索引

本索引记录模式一示例的输入材料评估状态。原始材料默认保持原名、原内容，不通过重命名表示已处理。

| 材料 | 状态 | 评估结论 | 吸收位置 | 后续 |
|---|---|---|---|---|
| 用户提出的“离线预算工具”目标 | 已评估 | 需要本地事实层、原生 `src/` 布局和无外部网络依赖 | `README.md`、`DEVLOG.md` | 无 |
| 未来的预算字段设计草案 | 待评估 | 尚未提供，不能预先假定字段、公式或 UI | 无 | 收到后先评估再决定是否采纳 |
| 历史目录中可能存在的 `[已读]` 材料 | 兼容识别 | 文件名不能单独证明内容已被吸收 | 本示例无该目录 | 如出现则结合内容核验 |
