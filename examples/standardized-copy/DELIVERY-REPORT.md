# 标准化副本交付报告

本文件是模式二交付报告的结构示例，不代表已经对真实项目执行复制。

## 复制范围

- 源项目：`<source-project>`
- 目标副本：`<target-project>`
- 源项目：只读
- 目标状态：应为空；非空时默认停止
- 真实 `.env`：不复制
- `.env.example`：可按项目事实选择性复制

## 必须提供的证据

- 源与目标路径在规范化、解析链接后相互独立。
- 复制前后的源文件清单、大小和 SHA-256 哈希一致。
- 目标没有源机器绝对路径或真实敏感值。
- 目标的关键文件、启动/构建/测试命令按适用性完成验证。

## 未执行

本示例没有执行源项目复制、Git 操作、远程操作或外部发布。
